## AS9929、95th 计费、3X burst 分别影响什么

这三个词都出现在联通精品网的参数里，属于网络计费术语，跟 CPU 无关。

AS9929 是中国联通的精品网线路。中文测评在 2025 年 10 月的记录里写，联通回程走 AS10099 + AS9929，电信和移动回程走 CN2。对国内用户来说，这条线路的价值在晚高峰不掉速。

95th 计费是按带宽的 95 分位值收费，不是按流量总和算。它适合流量波动大、峰值不持续的业务。个人用户基本用不到这个概念，看到“95th billing”知道它不是“用超了就断网”就行。

3X burst 指突发带宽可到基础带宽的 3 倍。页面写的基础网络是 100M，短时间能冲到 3 倍。持续跑满还是会落回基础速率，别把突发当常态带宽用。
